# 📋 Blogger 추가 블로그 생성 가이드

## 단계별 안내 (5분이면 완료!)

### 1단계: Blogger.com 접속

1. 브라우저에서 <https://www.blogger.com> 접속
2. Google 계정(<kr4ciy@gmail.com>)으로 로그인되어 있는지 확인

### 2단계: 새 블로그 만들기

1. 좌측 사이드바 하단의 **"새 블로그"** 버튼 클릭 (또는 드롭다운 메뉴)
2. 팝업창이 뜨면:
   - **이름**: `정부정책2` (또는 원하는 이름)
   - **주소**: `govpolicy2` (사용 가능한 주소 입력)
     - 예: govpolicy2.blogspot.com
     - 주소가 이미 사용 중이면 다른 이름 시도
   - **테마**: 아무거나 선택 (나중에 변경 가능)
3. **"블로그 만들기"** 클릭

### 3단계: 두 번째 블로그 만들기 (선택사항, 추천!)

위 과정을 반복:

- **이름**: `정부정책3`
- **주소**: `govpolicy3`

### 4단계: 블로그 ID 확인

PowerShell에서 실행:

```powershell
cd d:\AI\gov24
python list_blogs.py
```

결과 예시:

```
블로그 #1: Stories of people
  ID: 3345493778668670443
  
블로그 #2: 정부정책2
  ID: 1234567890123456789
  
블로그 #3: 정부정책3
  ID: 9876543210987654321
```

### 5단계: 블로그 ID 복사

위에서 나온 모든 **ID 번호**를 복사해서 알려주세요!
